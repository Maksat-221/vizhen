# Vision (Вижен)

Голосовой ИИ-ассистент в стиле Джарвиса: русский, казахский, английский.

## Mac — полное управление компьютером
Открой Терминал и вставь:

```
curl -fsSL https://maksat-221.github.io/vizhen/mac/install.sh | bash
```

Скажи «Вижен, включи музыку», «Вижен, открой Telegram», «Вижен, громкость 30», «Вижен, напомни завтра в 9 про экзамен».

## Телефон
Открой в Safari: https://maksat-221.github.io/vizhen/ → «Поделиться» → «На экран Домой».
